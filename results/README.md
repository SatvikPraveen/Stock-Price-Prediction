# Results

| Path | Contents |
|---|---|
| `latest/` | Tables, figures and provenance of the committed run; regenerated by `make experiment` (or `summarise_run()`), consumed by `scripts/update_readme.R`, `reports/report.Rmd` and the Shiny app |
| `runs/<run_id>/` | Every run (git-ignored): `forecasts.rds`/`.csv` with one row per (ticker, model, origin), `config.yml`, `provenance.json` (git SHA, R and package versions, data hashes), `sessionInfo.txt`, and the same tables and figures as `latest/` |
| `legacy_notebook/` | Plots and the in-sample "performance" CSV produced by the original exploratory notebook; kept for the project's history, not valid as forecast evaluation |

## Files in `latest/`

| File | Description |
|---|---|
| `leaderboard_return.csv` | One row per (ticker, h, model): n, RMSE, MAE, OOS R², directional accuracy, PT statistic and p-value, DM statistic and p-value vs `naive_zero`, CRPS, 95% coverage, Winkler score, refit count, mean fit time, error count. `ticker = POOLED` pools all tickers |
| `leaderboard_volatility.csv` | One row per (ticker, h, model): QLIKE and MSE against the squared-return (`r2`) and Garman-Klass (`gk`) proxies with DM p-values vs `hist_var` |
| `strategy.csv` | Long/flat and long/short backtests per (ticker, model) plus `buy_hold` and equal-weight `POOLED` rows: annualised return and volatility, Sharpe with Lo (2002) SE, max drawdown, total return, turnover |
| `cumulative_sse.csv` | Running sum of `e_RW² − e_model²` per ticker and model (h = 1), the data behind `figures/cumulative_sse_h1.png` |
| `summary.json` | Headline facts used by the README generator |
| `config.yml`, `provenance.json`, `sessionInfo.txt` | Exactly what produced the run |
| `figures/` | `cumulative_sse_h1.png`, `leaderboard_rmse.png`, `leaderboard_crps.png`, `leaderboard_qlike.png`, `equity_curves.png` |
